# My Store – E-commerce Website
## 🌐 Live Demo

[Visit My Store](https://nikhilsharma28.github.io/my-website/)
A responsive e-commerce website built using HTML, CSS, and JavaScript. The website fetches product data from an API and displays products in a user-friendly layout.

## Features

- Product listing using API data
- Product categories
- Shopping cart functionality
- Cart count and total price
- Responsive user interface

## Technologies Used

- HTML5
- CSS3
- JavaScript
- API Integration
- Font Awesome

## Project Purpose

This project was built to practice frontend development, API integration, DOM manipulation, and shopping cart functionality.
